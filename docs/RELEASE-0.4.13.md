## 0.4.13 新增

### 本地安装时间轴不再持有旧任务对象

新增 `jobs/LocalInstallTimeline.ets`：把**当前任务快照**投影成时间轴视图
（标题、版本、状态、每一步的文案与时刻）。页面只持有投影结果，不再自己挑一个
`InstallJob` 对象画时间轴。

原来的 `localTimelineJob()` 会在 `installedJobs`/`pendingJobs` 里按 id 找一个任务，
而这两个数组在每次快照推送时都会被**重建**。找得到与否取决于那一刻的过滤结果
（`pendingJobs` 只放未完成的），于是同一行在不同阶段可能指向不同对象，时间轴与
状态文案就可能停在上一次的快照上。现在一律从快照投影，不存在「持有的是哪一份」
这个问题。

配套改动：

- 删掉 `nowTick` 与 `activeStage` 两个状态：前者靠每秒自增驱动「用时」走字，
  后者只服务旧的时间轴。计时并入投影，进度条完成态不再依赖「最近 5 秒有没有
  tick」这种脆弱判断。
- `startStageTicker()` 改为幂等（已在跑就不再起第二个定时器），并在投影显示
  「进行中」时自动启动。
- 状态色调（正常 / 成功 / 警告）由投影给出，不再散落在模板里判断。

### 顺带覆盖的边界

- 同一历史行完成后 ForEach key 变化，转圈会消失。
- 等待类、可重试、终止性失败都保持可见且不转圈。
- 重启后终止状态能恢复；已完成任务的「用时」保持固定，不再随时间变化。
- 旧记录（没有新阶段信息的）仍按实际终止阶段显示。
