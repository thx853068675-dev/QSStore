# 本机 Profile 长期保留与优先复用

## 默认策略

Profile 是签名材料，不属于安装包缓存。存放在应用私有 `filesDir/signing-profiles`，不设清理 TTL，不受安装成功后的安装包清理、任务取消、历史记录清理影响。证书重置和登录退出也不删除此目录。应用正常覆盖升级、进程重启后继续读取原文件。

采用 `包名-证书编号-设备前缀-p-CMS文件SHA256.p7b` 的不可变文件名。同一份材料去重；权限、证书或授权时间变化产生新文件，保留旧文件，不覆盖其他安装任务正在引用的授权。复制文件先 fsync，再原子重命名。旧版普通路径和续签路径按需迁移，同时保留原路径，兼容旧安装任务。

## 重签顺序

1. 准备与当前账号配对的本机私钥、证书；覆盖更新优先选择与已安装签名匹配的可用证书。
2. 查询该包名、证书、设备的本机 Profile，包括旧版缓存与续签记录。
3. 核验签名 CMS、debug 类型、完整包名、完整 UDID、证书配对、有效期、需要的 ACL。文件名前缀只作查找索引，不能代替核验。
4. 在符合条件的本机材料中选择到期最晚的一份。续签另要求有效期确实超过旧授权；普通版本更新无需重新申请授权。
5. 本机没有合适材料时才请求 AGC。命中本机材料不查询设备登记、不申请授权、不触发回收网络请求，即使账号已达自动签名额度也可继续使用有效材料。
6. AGC 签发后先完成实际授权核验和持久化，再交给签装任务。明确返回云端记录编号时才保存并回收该条记录；没有编号不阻断文件使用，不删除猜测的记录，不重复成功的申请。

## 保留范围

- 不混用另一个证书、设备或当前账号不配对的签名身份。
- 过期、不匹配或缺少 ACL 的文件保留作为历史材料，但不参与重签。
- 长期保留文件不会延长华为签发的有效期；真正续期必须取得更长有效期的授权。
- Profile 必须有配套私钥和证书才能签包，单独保留 Profile 无法恢复丢失的私钥。
- 应用卸载或系统清除应用数据会清空私有目录。本策略保证正常升级及日常清理期间保留，不承诺卸载后仍能从沙箱找回。
- 单份 Profile 通常约 4 KB；当前保留多版本材料比重复申请更合理。未来若增加签名材料清理，应作为独立的显式操作，不能复用普通缓存清理。

## 本地管理与安装包清理

「我的」证书管理下方提供本地 Profile 入口，按 CMS 内核验出的完整包名分组。左滑记录显示删除操作；确认后删除该应用的本机授权文件，有未完成安装任务或原生收尾任务时拒绝删除。删除不影响已安装应用，不删除私钥、证书或 AGC 云端记录。无法识别的文件单独显示，不从文件名猜测包名。

只有确认安装成功才清理下载原包和签名产物；任务正在使用的文件仍被保留。启动时扫描安装器专用目录内没有任务或清理记录引用的旧安装包，保护刚创建的文件及正在导入的文件。用户自己选择的原始文件和签名材料目录均不在扫描范围。

同一包名可能有不同证书、设备、ACL 或授权时间的 Profile。旧版路径迁移时也可能留下同内容的兼容副本；相同归档内容不重复写入。这些文件不是可互换的申请名额，不能仅按包名自动删到只剩一份。
