# 管理页安装清单与返回体验（2026100208）

- 已安装分为商店应用、本地侧载，使用详情页同款切换控件并显示分组数量。
- 从设备 `bm dump -g` 获取调试签名应用，包含 release 编译但采用 debug profile 侧载的包；不遍历系统应用逐个取版本。
- 清单、实际名称、版本、启动入口保存在本机。首次识别需要无线调试，随后离线可展示和打开。
- 按真实包名合并设备识别、商店目录与安装记录；完整存在性清单确认已卸载后隐藏旧记录。
- Melotopia 当前仓库含普通版 `cn.chenlvin.melotopia.hm` 与 HiCar 版 `cn.migu.music`。两者不是同包的两个安装版本；都存在时分别显示，并标记 HiCar。
- 本地导入图标独立缓存，按包名及构建区分，最多 8 MiB；系统拒绝图标及其他应用 HAP 目录访问时，外部工具安装且从未导入的应用可能仍显示占位。
- 设备单包查询失败保留已知信息，异常或截断清单不清空缓存。自动识别合并重复调用，60 秒缓存，并避开执行中的安装任务。
- 返回发现或管理仅合并详情已读取的变化，保持分页、搜索、滚动位置和旧图标，待新图标读取完成后替换。
- 回到顶部的原生 Popup 锚点随页面返回重新创建，离开页面移除，避免旧 Popup 被系统关闭后无法恢复。
- NAPI 的 HDC 操作范围与 Rust 保持一致：新增只读清单/名称操作 13、14，并补齐已有暂存/清理操作 10–12。
