# 51 预览版本地卸载状态修复

- 根因：管理页使用安装历史、商店识别与本机清单合并显示。刷新将确认卸载写成内存版本 0，却从持久化缓存中删除该项。下次启动读取安装历史时，状态成为未知（-1），旧记录重新参与「已安装」展示。
- 修复：版本 0 作为已确认卸载状态写入本机缓存，并在下次启动恢复；卸载状态不随正数版本缓存的 30 天期限失效，真实设备确认重新安装后可更新为正数。清除卸载项的侧载标记和启动入口。
- 并发修复：启动读盘期间已有实时观察的包，不再被旧磁盘状态覆盖，包括未落盘的卸载结果。缺失或类型错误的版本字段仍视为损坏缓存，不冒充已确认卸载。
- 回归测试先复现旧代码失败，再确认修复通过：卸载→刷新→进程重启且保留安装历史；超过缓存期限仍不复活；迟到的启动读盘；真实重新安装重新进入列表。原有断连、查询失败及损坏清单保留已知安装状态的测试继续通过。
- 客户端 382 项测试通过，全量构建 33/33 通过，递归内外包无签名检查通过。此修复以执行真实 ArkTS 方法的主机回归测试验证，未在用户设备上卸载应用做破坏性测试。
