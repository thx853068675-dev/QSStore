# 轻启·安装器 0.4.47：修复上架图标

服务端过去按 ZIP 文件名中的 `icon` 猜应用图标，会选中工具栏图片，甚至把 1×1 的 `startIcon.png` 当成应用图标。现在只读取所选 HAP 的 `module.json` 中声明的 `app.icon` / `iconId`，通过 `resources.index`（RestoolV2 和 Restool 6）定位资源；分层图标按前景、背景合成为 PNG。解析失败时不再使用 GitHub 仓库所有者头像冒充应用图标。多个 HAP 使用相同包名时，优先使用上架时选定的文件名。

目录接口新增 `icon_rev`。客户端按修订号核对本地图标缓存；服务端更新图片后，发现页会自动重新获取，详情页继续从服务端读取图标。图标接口不再返回仓库头像重定向。GitHub HAP 临时下载失败时，同一摘要下已经验证过的包名和版本元数据会保留，避免定时采集清空可安装版本。

## 验证

- 服务端 50 项测试通过，新增清单引用、两种资源索引、分层合成、图标修订号和下载失败恢复测试。
- 14 个在架应用的 HAP 均按 GitHub 提供的 SHA-256 校验后解析；10 个线上旧图标与声明图标不符，已替换。逐个核对生产 API 返回的图标字节与修订号。
- 贴吧 Lite 原图标是 1×1 占位图；修正后为 512×512 的蓝色分层图标。
- 新上架的 ClashBox 使用 Restool 6 格式，已经按其 HAP 清单合成猫咪图标。
- 0.4.47 官方 SDK 签名、验签通过；HarmonyOS 6.1 设备 `3BH0224320005595` 覆盖安装、启动、版本核对通过。发现页确认贴吧 Lite、鸿米家、PiliPlusX、FlClash 等图标已更新。

产物 `native/dist/quietstart-installer-0.4.47-device6.1-signed.hap` 使用 AGC 调试 Profile，只适用于已授权的设备。面向其他设备仍需正式发布证书和 Profile。
