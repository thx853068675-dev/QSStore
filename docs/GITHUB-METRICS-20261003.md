# GitHub 下载量与 51 预览版验证

## 数据口径

- `github_downloads` 为仓库全部非草稿 Release 附件的 `download_count` 之和，包含正式版和预发布版。GitHub 自动生成的源码归档不在附件统计中。
- 在筛选 HAP/APP/ZIP 和展开压缩包之前汇总，避免一个 ZIP 内的多个 HAP 被重复计数。
- 数字与星星数并排，达到 1000 后显示 K；发现页和详情页使用同一组件。旧服务、旧缓存和未采集的数据隐藏下载量，真实 0 保留。
- 下载量不是安装成功数或独立用户数；镜像、本地缓存不会逐次产生 GitHub 下载，删除后重新上传附件也会重置该附件的 GitHub 计数。
- 沿用现有分页采集和 SQLite 列表批量查询，不增加客户端 GitHub 请求或单应用逐条统计查询。缓存快照保留完整版本历史，导入导出保留统计字段。
