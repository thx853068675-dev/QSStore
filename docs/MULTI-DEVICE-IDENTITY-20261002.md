# 多设备证书与悬浮材质修复

候选版本：0.4.49-preview.1，内部编号 2026100207。

## 证书

- 旧备份每账号只有一个槽位。不同设备使用不同证书时，备份 CAS 冲突；重置又读取账号默认备份，形成无法恢复的循环。
- 新客户端按 `account_id + cert_id` 分别备份，通过 `backup_scope=certificate` 上传、`?cert_id=` 精确读取。同一证书的私钥不可覆盖；密文同时绑定账号及证书。旧客户端的主槽位和 CAS 协议保留，轮换时在同一事务中归档旧身份。
- 本机已有配对材料时，重置直接使用本机私钥向 AGC 刷新，不读取商店备份。AGC 已删除或证书过期时，先扫描同私钥的可用证书；找不到且有槽位才申请。保留原私钥，不删除其他设备证书。查询或配对失败保留原材料。
- 云端备份仍由商店服务器保存，不是 AGC，也不是端到端加密。是否改为可选文件备份属于后续策略选择，本修复没有取消现有迁移及自更新恢复能力。
