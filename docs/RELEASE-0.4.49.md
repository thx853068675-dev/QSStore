# 轻启·安装器 0.4.49

## 更新

- 支持本地 APP、HAP，以及包含 APP/HAP 的 ZIP；先预览软件信息，再加入安装队列。
- 上架支持多个安装包同时选择，应用详情可选择安装包；压缩包由服务端后台检查。
- APP 内各 HAP 模块统一重签并提交安装，保留内嵌工作模块重签。
- 接入官方后台长时任务，修复下载挂起后返回前台被误判超时。
- 优化沉浸布局、详情顶部、安装进度裁切、星数对齐与队列按钮。
