# 轻启·安装器 0.4.49 预览版 1

日期：2026-10-02。此版本标记为预发布，正式版 0.4.49 的制品保持原样。

## 更新

- 详情页并列显示「正式版 / 预览版」，选中项带勾选、描边与短过渡，支持深浅主题；切换失败恢复原选择，并避免与检查更新重复请求。
- 无任务时进入后台自动释放无线调试，回到前台静默恢复已保存端口；安装、排队和应用扫描期间保留连接，避免生命周期切换打断工作。
- 发现页识别按钮显示连接、扫描状态与实际核对进度，识别完成后收起卡片。
- 发现页顶部加强系统磨砂、半透明底色与柔光，保持向下渐隐和深浅主题适配。
- 全局安装队列由进程统一执行，修复多包仓库更新目标、跨页面连接和数据清除确认。
- 普通应用重装先预传并校验新包，再核对已安装身份后卸载安装；暂存票据持久化，重连后继续清理。
- APP 解析复用、存储预检查、完成缓存回收、下载错误内容换源、账号静默恢复。
- 服务端采集排队去重、解析与 HTTP 条件缓存、批量目录 SQL、减少轮询写库；详细改动见 [优化记录](LOCAL-OPTIMIZATION-20261001.md)。
- README 简化为项目简介、下载及构建入口。
