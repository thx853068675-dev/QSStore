# 原生预览版在 HarmonyOS 6.1 的验证记录

设备：HBN-AL00，HarmonyOS 6.1.0.135，HDC `3BH0224320005595`。原生预览版包名为 `com.tonghongxiang.hapstore.nativepreview`，与现有正式安装器并存。

## 签名与设备

- 未签名 HAP 被设备拒绝，错误码 `9568320`；因此没有把未签名产物当作可交付包。
- 沿用现有私钥和已配对的 AGC 调试证书，为预览包独立申请 Profile；脚本没有申请新证书，创建前 AGC 列表有 4 张调试证书。
- `tools/make_hapstore_profile.dart --bundle ...` 复验 Profile 包名、设备 UDID、证书和私钥配对。`native/tools/sign_preview.py` 用官方 SDK 签名并执行 `verify-app`，没有把私钥、P12 或 Profile 提交到仓库。
- 已签名预览包成功安装；现有正式版仍为 `2026092736`，`aa start` 成功。本次预览版版本码为 `2026092803`，经本轮重装核对，SHA-256 为 `b25b5a925573fbc087e83f52807c9b68d8c7504287f62e7abefa1b302dafa0be`。该 Profile 绑定本次设备，产物不等同于可直接分发给所有设备的正式包。

实机中发现并修复了两个问题：本地导入在下载目录已存在时抛出 `File exists`；商店附件只使用 GitHub 直链，未利用服务端镜像列表。修复后本地导入复测通过，商店附件校验完成。镜像自动轮换逻辑已编译并在设备运行，但本轮没有证明发生了实际切换，不能把它记为已完成的断网容错验收。

尝试通过 `bundleManager.getBundleInfo` 判断其他应用是否已安装时，设备返回权限错误 `BusinessError 201`，明确要求 `GET_BUNDLE_INFO_PRIVILEGED`；仅在模块清单声明 `GET_BUNDLE_INFO` 无法解决。已撤回该失败实现，等待原生设备通道接入。

登录实测发现 DevEco 临时令牌接口会直接返回纯文本 JWT，原生端原先按 JSON 解析会报错。现已兼容纯文本和 JSON 字符串，登录等待窗口延长至 10 分钟。浏览器授权回调完成后，公开昵称及头像在“我的”和评论中显示。评论提交成功后，原界面用数组下标作卡片键导致旧评论短暂错位；现直接采用服务端写入响应刷新列表，并以内容和时间组成稳定更新键，第二条评论实机提交后立即显示。

服务端 17 组 `unittest` 回归通过，覆盖多次评论不覆盖、公开头像回填、两阶段上架及下架授权。下架操作仅经服务端测试；没有下架当前真实上架应用，以免中断现有商店。

## 预览版 0.4.0：源码 HDC 安装与端口变化

- 用 MIT 许可的 Muka Rust HDC 源码构建进程内 TCP 主机，沙箱保存独立 RSA 主机密钥。设备首次连接时弹出系统“是否信任此设备”，选择始终信任后 UDID 获取成功。包内仅有自编译 `libhap_core.so` 和工具链 `libc++_shared.so`，不含旧 `libhdc_z.so`、Flutter 或 Go signer。
- 6.1 设备上的 `com.tonghongxiang.popupfixture` 先经主机 HDC 卸载，再由 0.4.0 预览版管理页的安装任务调用应用内源码 HDC 重新安装。任务变为“已安装”，主机独立执行 `bm dump` 读出 `versionCode: 1`。Rust HDC 安装命令仅返回 `AppMod finish`，客户端已改为查询设备实际版本确认成功，不依赖成功文案。[操作截图](native-preview/sourceonly-action-6.1.jpeg)
- 关闭再开启 6.1 的无线调试，设备显示端口从 `45671` 变为 `42887`。预览版没有在断开时跳页；管理页点击“校验”才弹出无线调试连接层。[重连截图](native-preview/port-reconnect-6.1.jpeg) 输入新端口后弹层关闭。随后通过主机卸载测试 HAP，再次在管理页点击“校验”，应用内 HDC 按已保存新端口直接重装成功；主机独立读取 `versionCode: 1`。无线调试保持开启。
- 应用详情的悬浮蓝色安装按钮、版本选择、来源仓库和评论头像已在 0.4.0 实机复核。[详情截图](native-preview/detail-native-0.4.0-6.1.jpeg) 目前设备上的轻启正式版版本码高于商店可选的 1.1.0 历史包，因此没有强行执行降级安装；任务恢复逻辑按相同版本码判断安装完成，不会把更高版本误记为所选历史版本。
- 本次候选预览包为 `com.tonghongxiang.hapstore.nativepreview`，版本码 `2026092808`，产物位于 `dist/qingqi-native-preview-0.4.0-device6.1-signed.hap`，最终 SHA-256 为 `71e1c1dbb6c3b7b494d217c47c93382cd9abd048ded37c5e3ec82441ebf10eac`；它的 Profile 绑定本次设备。正式包覆盖更新、旧版沙箱迁移、自更新、7.0 和更多故障注入仍需分别验收，不能从上述测试推断已完成。
