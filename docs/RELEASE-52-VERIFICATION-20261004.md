## 证书与签装恢复

- 官方文档写每账号最多 3 张调试证书：<https://developer.huawei.com/consumer/cn/doc/doccenter-getting-started/agc-help-debug-cert-0000002283256797>。
- 7.0 HoKit 实际列出 4 张调试证书且均未过期；用户 AGC 控制台截图同时确认 4 张为生效调试证书。实际额度不能由客户端固定数量推断。移除 `DEBUG_SLOT_LIMIT`、推算剩余槽位与最后一槽确认逻辑，逐张配对复用后才申请，由 AGC 明确超限结果判定。
- 只有 cert/add 的明确数量超限归类 `CERTIFICATE_LIMIT`，持久化为 `WAITING_CERTIFICATE`。登录、权限、网络和 Profile 额度不会触发证书删除窗口。
- 弹窗跟随当前可见页面；首次没有本机身份时也可列出、选择证书。不可撤销删除先展示影响说明并要求明确点击。关闭只保留等待，重新继续可再次打开。
- 删除成功自动恢复同一个任务，保留原包、Profile 路径、私钥与用户已有同意。失败不恢复；丢失响应重新查询是否删除，不盲目撤销墓碑；账号变化、任务取消及跨页面重复操作均有保护。
- 12 项证书行为测试包含真实生产 JobRunner 的“超限暂停 → 删除 → 使用原缓存完成安装”、4 张已有证书不误拦、路线切换、失败和取消保护。未为了测试删除用户实际证书。
- AGC 证书“使用”和“已使用”共用按钮尺寸/颜色/圆角；左滑删除为上方图标、下方文字，红色背景并留间距。
- 短暂提交故障最多自动恢复一次且先核对安装结果；明确签名/授权/BM 错误不重试。安装结果短暂查询失败最多重查两次，不重签或重新传包。原报告的 check diff 完整原文尚未获取，不声明复现该原始错误。
