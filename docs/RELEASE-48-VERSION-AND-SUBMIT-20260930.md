# 0.4.48 当前版本与上架检查修复

## 当前版本显示

设备系统读出的已安装版本为 `0.4.48` / `2026093012`，管理页却显示历史安装的 `0.4.45`。此前在线安装只保存 HAP 构建码，缺少版本名时还可能显示日期形状的内部构建码。

修复后，管理页的当前安装条目使用系统版本，历史记录保留原始版本；自查询不要求查询其他应用的权限。下载和签名检查均保存 HAP 实际版本名。同名版本存在更高构建码时显示“有修订更新”。当前公开替换包保持版本名 `0.4.48`、构建码 `2026093015`，不再次增加构建码。

## 上架检查

旧实现把所有检查（含失败、无效地址）记入同一 IP 的每小时三次额度。这与上架应用数量无关，共用网络的用户还会互相占额度。

- 改为每个已验证账号每分钟三次实际预处理。
- 无效地址不占额度；真实采集失败仍计入分钟额度，防止反复失败请求消耗上游配额。
- 同一账号、同一仓库五分钟内复用持久化的完整检查结果，不再次下载 HAP，也不占额度。
- 限流响应正文及 `Retry-After` 使用实际剩余等待时间。
- 旧草稿数据库自动补充缓存字段，保留现有草稿和选择内容。

服务端已部署，旧版客户端无需更新即可使用新的检查额度。
