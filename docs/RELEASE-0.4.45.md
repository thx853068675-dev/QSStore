# 轻启·安装器 0.4.45

## 自更新修复

- 安装器自己的更新包保留发布时的签名；使用用户 AGC 证书重签会改变签名身份，无法覆盖已安装的安装器。
- 对自更新包核对下载摘要、包名和版本号，交给 HarmonyOS 包管理器验证原签名。内置 HAP 校验器无法解析华为 SDK 生成的部分签名块，不能用它拒绝官方发布包。
- 安装前重新验证无线调试连接；端口变化时丢弃旧会话，只自动重试一次旧端口。
- 安装结果未及时反映时保留原始错误，不把它一律解释成断线。
- 发现页和详情页按当前 Release 附件选取安装任务；旧失败任务不会遮挡新版进度。目录摘要与实际下载摘要不同时仍沿用同一任务。

## 验证

- 客户端单元测试：126 项通过。
- 官方 SDK `verify-app`：0.4.45 HAP 通过。
- HarmonyOS 6.1 设备 `3BH0224320005595`：0.4.43→0.4.44 通过详情页在线升级，0.4.44→0.4.45 通过发现页在线升级。两次升级后应用进程均按系统预期结束；重新打开后发现页为「打开」，管理页显示当前版本，无无线调试重连弹窗。

## 迁移与分发范围

- 0.4.42 及更早版本尚未包含自更新修复，需要一次直接安装 0.4.45；此设备已完成迁移。
- 当前 HAP 使用设备专属 AGC 调试 Profile，只适用于获授权的测试设备。面向其他设备分发需要正式发布证书与 Profile。
