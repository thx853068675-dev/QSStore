# 51 预览版复核修复

## 安装状态

页面显示观察和跨页面安装状态按照观察时间取最新值。本地系统安装确认会更新并按需持久化版本缓存，卸载后的本地重新安装不会再被旧页面的 version=0 遮蔽。历史安装记录仍不能推翻设备确认卸载。

## 完整清单

原生 `bm dump -a/-g` 仅在命令成功结束后输出 `__QINGQI_BUNDLE_LIST_END__`。解析器要求完成标记、完整行和有效清单格式，连接中断产生的部分数据不会写入卸载状态。兼容系统元服务的数字包名段。

本次 7.0 设备未连接。6.1 设备只读执行相同 shell 命令后，生产解析器接受完整的 256 个已安装包与 5 个侧载包；未执行卸载或重装。

## 大 HAP 图标

Range 读取器保留 I/O 失败标志，区别于无图标或不支持的图像。已证明的包元数据继续缓存，图标失败以 5 分钟起步、最多 1 小时的退避重试；成功后复用缓存。旧的无图标缓存重新检查一次，原有成功图标继续复用。仍保持官方域名、字节/请求/时间预算，不下载大包本体。

## UI

共享版本标签居中排字并向下补偿一个随字号缩放的 vp，覆盖发现普通/星空卡片与应用详情。未声称本次完成 7.0 视觉实测。
