## 0.4.16 新增

### 应用详情

- **来源仓库卡片**去掉右上角的 `↗` 与「点击用浏览器打开 …」一行。卡片本身仍在、
  仍可点击打开仓库，只是不再用两处装饰说明它可点。
- **安装按钮上方那行进度文字**去掉。按钮本身就是进度显示（Canvas 波浪前沿 +
  文案带百分比），上面再挂一行纯文字既重复又占高度。

> 那行文字原本也是**唯一**的失败原因展示位（安装失败、未登录、任务仍在收尾等）。
> 直接删掉会让「点了没反应」，所以把这些结果改为**瞬时提示**（toast），同样的内容
> 不重复弹。阶段轮询每秒都会跑一次，那里只弹失败原因，正常阶段不弹，避免刷屏。

### 我的

- 证书管理里「已安全复用现有调试证书 · 未占用新槽位」不再显示。复用成功是正常
  状态，不需要一行说明；该字段继续用于报错与需要用户动作的提示（未配对、
  重置失败等）。
- 设备连接下的「设备的无线调试同时只服务一个调试宿主…」整段说明删掉。
