# 本地授权、安装包清理与界面验证

## 实现范围

- 本地 Profile 弹窗按实际签名内容分组，保留固定标题和关闭入口；记录左滑显示删除操作，卡片与删除操作间距 8 vp。删除前重新核验文件和当前任务，不删除正在使用的授权。
- 证书到期后才显示重建；已有日期旁追加「已到期」，去掉独立的临近到期提示及证书已就绪的重复说明。
- 确认安装成功后清理下载包、签名包和模块临时包，保留安装记录、到期信息、Profile、私钥和证书。失败或等待继续的任务不按安装成功处理。
- 启动时清理安装器专用目录内的孤儿安装包，保护任务引用、取消清理记录引用、导入预留和十分钟内的新文件，拒绝跟随符号链接。
- 保留系统导航手势条，先恢复系统栏再应用透明底色；主题变化及返回前台重复同步。
- 应用详情、本地签装和包编辑共用 `StorePageHeader`，返回符号与标题合并为系统沉浸光感胶囊，复用顶部渐变。退出前关闭原生材质浮层，防止多个返回回调叠加。
- 详情主操作在支持的设备上使用系统光感，蓝色通过 `materialColor`（99 透明度）加入系统材质，按钮内容层透明并保留原进度显示；不支持系统材质时仍使用原来的蓝色按钮。底部浮层使用向上布局和正偏移，避免系统避让翻转后再次被负偏移抬高。
- 长应用名只移动溢出部分，到边界停留后往返；离屏或销毁会停止计时和动画。短名称保持静止，版本标签不参与滚动。
- 未配置子仓时，版本列表及选中版本均不显示主仓/子仓字段。
- HDS 标题栏从默认自适应模糊改为固定启用，并关闭下拉位移对模糊的影响；不在每帧重绘整个目录页。
- 管理长按菜单改用右上角关闭按钮和遮罩点击关闭。原 `HitTestMode.Block` 会拦住子按钮，改用 `Default` 允许内部操作并阻止穿透到遮罩。
- 禁止四个主导航页左右滑动切换。安装队列和已安装列表支持左滑，复用长按菜单的实时动作检查；上方图标、下方两字说明，危险操作用红色警示背景，卡片提示统一为左滑。
- 本地签装、包编辑、应用信息页忽略系统布局避让，让内容绘制到透明系统栏下方；包编辑使用列表内容偏移，滚动时卡片可以进入顶部渐变区域，不留下固定留白。模糊背景与渐变蒙版在同一合成层中，按主题着色，避免独立白色矩形。
- 本地签装与包编辑的“＋”改为通用系统光感按钮；忙碌进度保留在同一个按钮中。本地和“我的”主页面接入与管理页同样的 HDS 渐变标题栏。

## 同版本包编辑签装核对

- 「直接签装」先生成修改包，再复制到独立的本地预览，显式提交后由 `enqueueLocal` 持久化 `reinstallRequired=true`。恢复和提交阶段均不会仅因包名、版本号相同而跳过安装。
- 编辑器修改应用与桌面入口的标签、图标资源索引；APP 的内层 HAP 和外层元数据也同步处理，包名未改时版本编号保留。
- 包编辑、本地预览和原生安装相关 98 项测试通过，包含真实 HAP/APP 名称、图标读回及原始包保持不变；这不能替代任意第三方包的实际覆盖安装验证。
- 保留数据取决于系统是否接受覆盖签名身份；不兼容时需用户确认卸载重装，不能用包名相同推断可保留数据。

含账号、设备授权及安装数据库的证据仅保存在仓库外临时目录，不提交私钥、凭据或完整 Profile。

## 未知期限改为预计日期

- 管理列表与应用信息页同步。已绑定到当前安装构建的期限仍显示「到期」；未核验的日期显示「预计到期」，不再使用未知或待确认文本。
- 估算优先匹配包名、实际证书指纹、应用标识及安装时间。当存在多份匹配 Profile，选择安装前最近签发的记录；同时间签发记录取较早截止日期。
- 没有同应用 Profile 时，根据同证书的本地授权记录中最常见有效期推算，并以该证书的期限封顶。完全没有匹配材料时，以系统最近安装/更新时间加 365 天估算；系统时间读不到时使用持久化的首次观察时间或安装记录。这个默认值只是估算，不表示其他工具的授权实际都是一年。
- 安装时间独立于证书元数据保存，刷新同版本不会移动首次观察时间；版本变更和卸载会失效旧基线。估算不写入已核验授权、不参与自动续签触发、不产生 AGC 或商店服务器请求。
- 本机历史 Profile 只读统计：35 份有效期为 365 天，5 份为 14 天，因此不将当前账号证书日期套用到其他证书签装的应用。
- 601 项宿主测试通过，涵盖时间缓存恢复、卸载与版本变更、不同证书隔离、14 天有效期优先、证书期限封顶、展示与已核验期限隔离及刷新竞态。全量 ArkTS 构建通过；已覆盖安装到 7.0。管理页与应用信息页实测 HoKit 均显示「预计到期 2027-09-23」。

## 已安装列表排序

- 商店应用与本地侧载共用排序规则：有更新的先显示；同组内按显示的到期日期升序，包含预计日期，已过期的在该组最前。相同日期保持原顺序。
- 排序只读取本地状态，每个条目的到期时间只读取一次，复用标签的日期解析，不查询设备、不访问 AGC 或服务器、不修改安装历史。
- 排序回归覆盖两个分组、更新与日期优先级、已过期、真实与预计期限、相同期限及刷新后状态变化。603 项客户端测试通过。
- 7.0 正式候选已确认本地列表顺序：HoKit 2027-09-23 → store_monitor 2027-10-02 → AloeSend 2027-10-04；管理页与 HoKit 应用信息页日期一致。设备当前没有可更新的应用，更新置顶由行为测试验证。
