# 轻启·安装器 0.4.48-preview.1

本次为 48 预览版，普通更新渠道继续使用原 0.4.48 正式版。可在安装器详情的「版本记录」切换「预览版」并手动选择。

## 改动

- 发现页安装、更新、打开按钮垂直居中；星数回到分类与版本信息区。
- 单层悬浮搜索框、滚动渐变模糊与透明系统栏，保留鸿蒙原生沉浸光感。
- 统一深浅色、留白、图标按钮、弹窗与选择框；星光卡背景随真实高度调整。
- 整理详情与评论布局，安装按钮使用平滑进度和细流光；连接按钮内显示加载反馈。
- 管理队列操作分行、本地 HAP 先预览、上架与配置表单优化。
