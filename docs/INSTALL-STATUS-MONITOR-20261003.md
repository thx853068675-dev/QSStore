## 管理页图标

- 根因：管理页依赖发现页的 `appIcons`。发现搜索/首屏刷新会裁剪这个数组；图标加载还要求应用在当前发现结果中，因此管理页无法加载不在该结果中的已安装图标。
- 管理页改用独立像素集合，按已安装、正在安装、自己上架的应用 ID 去重，先复用匹配修订的发现图标或恢复已有磁盘缓存，再按需获取缺失图标。搜索和发现刷新不会清空这份集合。
- 每个应用、图标修订共用在途请求，四路加载，解码至 192px；没有请求全目录图标。网络失败保留旧像素并允许下次进入/刷新重试；陈旧修订不覆盖新修订，缓存损坏可自动重新获取。
- 新增 8 项生产方法测试，覆盖搜索切换、冷启动离线缓存、共享请求、并发限制、失败重试、修订变更、共享发现像素与损坏缓存恢复。
