# 调试证书与跨设备签名身份

AGC 一个账号最多保留 3 张调试证书。证书只包含公钥；新手机无法仅凭登录从 AGC 取回签发时使用的私钥。因此星仓在登录后自动把第一台设备的签名身份同步到商店服务，新设备先取回同一华为开发者账号的身份，再逐张下载 AGC 证书并验证公私钥配对。成功后直接复用旧证书，不再占用新槽位。应用的设备授权仍按包和 UDID 在本机生成及缓存。

## 安全与运维

- 同步接口只接受华为 DevEco JWT；服务端每次缓存失效时向华为核验账号 ID。不同账号不能读取对方的私钥。
- 客户端只连接固定的 HTTPS 服务并校验证书指纹。服务端用 256 位随机密钥和 AES-GCM 加密私钥后写入 SQLite；密钥单独存放于 `/var/lib/hapstore/identity-vault.key`，文件权限为 `0600`。首次写入的身份不能被另一设备静默覆盖。
- 服务端需要 Python `cryptography` 包。数据库与 vault key 必须一起做管理员级备份；只备份数据库无法恢复加密身份。不要把 vault key、数据库或私钥加入 Git 或公开制品。
- 公开昵称来自华为 `GOpen.User.getInfo` 的 `displayName`（`getNickName=1`），服务端核对返回的 `userID` 与登录账号一致。不读取或展示证书主体里的实名；资料接口不可用时显示完整账号 ID。
- 用户不需要备份密码、文件选择器或手工移动私钥。`123456` 是弱密码，不用于保护签名私钥；随机 vault key 由服务端自动生成。
- 如果服务器或华为身份核验暂时不可用，新设备停止申请新证书并提示稍后重试，避免因网络故障占满 AGC 槽位。本机已有可用证书时可继续使用。

## 无法自动复用时

2026-09-27 实测账号已有 `hokit_debug`、`hapstore-debug-10c2a6098e` 和 `hapstore-desktop-debug` 三张证书。旧版本在云同步上线之前创建的私钥如果已经丢失，服务端也无法恢复它。程序不会按年龄自动删除任何 AGC 证书，因为 HoKit、另一台设备或桌面构建仍可能使用它；删除会影响这些应用后续更新。此时需要由持有者确认该证书已不用，或者从仍保存私钥的旧设备自动同步。桌面构建脚本默认也不会再新建证书，除非显式传入 `--allow-new-cert`。

## 已完成的防重复申请

- 私钥仍在而 CSR 丢失时，用原私钥补建 CSR。
- 复用 AGC 证书时逐张校验公私钥；本地已有配对证书时不再下载。
- 账号云端身份优先于生成新密钥；服务不可用时不继续占用新槽位。
- 无线调试连接不为商店自身另申请 Profile；各应用 Profile 按包缓存并在 UDID、有效期或 ACL 变化时重建。
