# 卸载回执修复（2026-10-04）

## 实际问题

7.0 管理页显示 `卸载未完成：Error: Error: HDC command: peer closed`。
设备系统日志同时记录多个应用已经卸载，完整的 `bm dump -a` 清单中也已不存在。
这次提示来自回执处理失败，不能据此认定系统没有卸载应用。

- Rust `app_uninstall_task` 只把回执打印到标准输出，没有存入供 ArkTS 读取的 `output`。
- 它把正常的命令通道 EOF 当成错误，因而丢失最终结果。
- 旧 AppUninstall 转发器还有两秒空闲关闭逻辑，不适合慢卸载。

## 修复

- 卸载接收使用共同的响应累积逻辑；正常帧边界 EOF 可以结束命令，截断的帧仍报错。
- 安装器的卸载操作改用 `shell bm uninstall -n <已校验包名>`，等待系统命令结束。
- 明确的系统成功回执直接完成；没有明确回执时，只读核对带结束标记的完整应用清单。
- 应用仍存在时最多核对六次，间隔 500ms；不会重复发送卸载请求。断连、截断清单不能被当作卸载成功。
- 核对期间保持「卸载中」，并阻止后台空闲断连。只有确认成功后才持久化未安装状态。
