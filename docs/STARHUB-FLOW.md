## 二、三步走（替代原来的「导入三个文件」）

```
① 登录华为开发者账号
     一次登录，自动完成：
       生成本机唯一密钥对 → 生成 CSR → 申请调试证书 → 申请安装授权
     全程不需要 OpenSSL、不需要文件导入

② 连接无线调试
     自动发现本机调试端口并连上

③ 开始使用
     商店列表的「安装」直接一键签名安装
```

### ⚠️ 修正：端口必须由用户填写（原设计前提是错的）

本节原先写的「自动发现端口」**不可行**，实测推翻：

```
读取 /proc/net/tcp       失败：Permission denied, errno = 13
读取 /proc/net/tcp6      失败：Permission denied
读取 /proc/self/net/tcp  失败：Permission denied
读取 /proc/self/net/tcp6 失败：Permission denied
```

**HarmonyOS 沙箱不允许普通应用读取 `/proc/net/tcp`。**
（用 `hdc shell` 能读，因为 shell 权限更高 —— 这正是我最初误判的原因。）

第二个错误假设是「调试端口在 loopback 上」。实测该设备的调试端口绑在
**WiFi 网卡与 `0.0.0.0`** 上，loopback 上的三个端口都与调试无关：

```
192.168.3.160 :46749  uid=1024
192.168.3.160 :62110  uid=1024
0.0.0.0       :39777  uid=2000
127.0.0.1     :59362  ← 不是调试端口
127.0.0.1     :9956   ← 不是
127.0.0.1     :7890   ← 不是
```

**原「小白」的做法也是让用户手填**（硬编码 `port = "12345"`，
由 `connectDevice(ip, port)` 接收输入），说明这一点在 HarmonyOS 上
本来就是无法自动化的。

**现在的做法**：第②步以**手填端口**为主路径，并给出准确指引
（「设置 → 系统 → 开发者选项 → 无线调试」页面上会显示端口号）。
自动尝试仍保留（万一将来沙箱放开），但失败时如实说明原因，
不再给出含糊的提示。

## 三、一键安装

### 3.1 列表项直接可装

「今日」「应用」「搜索」三个列表的每一项右侧都有**安装**按钮：

```
┌──────────────────────────────────────────┐
│ [图标]  应用名                    [ 安装 ] │
│         副标题                            │
└──────────────────────────────────────────┘
```

按钮四态：`安装` → `下载中(环形进度)` → `重签中` → `已安装`

### 3.2 状态集中管理

新增 `InstallCenter`（全局单例，随主壳创建）：

- 同一应用在**列表页与详情页显示同一份进度**（不会出现两处各跑一遍）
- 已安装的应用按钮变为「已安装」
- 失败后按钮变为「重试」

### 3.3 一键安装实际做的事

```
点「安装」
  → 拉取该应用最新版本，选中第一个 .hap 附件
  → 下载（多镜像竞速 + SHA256 校验）
  → 从包里读出权限声明（每个应用不同，建 Profile 要用）
  → 预检：证书 / Profile / 本机 UDID / 有效期
       └─ 不通过 → 自动调 AGC 重建授权 → 复验
  → 用本机密钥重签
  → 通过无线调试通道安装
  → 登记到「已获取」（供「更新」页比对版本）
  → 清理中间产物（HAP 可能几十 MB）
```

> **权限声明为什么必须在安装时读**：创建调试 Profile 时，AGC 需要
> 「包内声明 ∩ 可授权白名单」作为 `aclPermissionList`。每个应用的权限不同，
> 所以要在签名之前从待装包里读出来（`readDeclaredPermissions`）。
> 这一步做完，`9568289`（权限授予失败）才会被正确避免。

| 项 | 状态 |

| ~~端口自动发现~~ | ❌ **已证不可行**：沙箱禁止读 `/proc/net/tcp`，改为用户手填 |

建议的验证顺序：

1. 装上星仓，走一遍三步（第 ① 步会验证 AGC 全链路）
2. 第 ② 步若自动发现失败，界面会列出发现的候选端口，手填一次即可确认端口是否正确
3. 从商店装「轻启」—— 它带 3 个原生库，正好验证第 3 项风险
