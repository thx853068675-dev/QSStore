# 轻启·安装器 0.4.68

- 新增出海应用分区与标记，优化切网和商店刷新。已安装、已关注的应用可继续查看和接收更新。
- 支持游客浏览和海外华为账号登录。会话异常时引导重新登录，未实名可直接前往认证。
- 支持网页绑定 GitHub、认领应用并接管上架。可修改应用名、介绍和最多 6 张截图。
- 详情页新增带壳截图和全屏滑动预览，README 按界面语言优先显示中英文版本。
- 评论支持单层回复、长按复制和链接跳转。认领作者有身份标记，作者和上架者可管理评论。
- 新增主题背景，支持渐变、自定义图片，以及独立调节卡片和图片遮罩的不透明度。
- 首页支持长按关注并显示标记，优化横滑切页，底栏自动隐藏可配置。
- 优化分栏安装按钮动效，修复旋转后顶部按钮消失和平板横屏详情偏左。
- 本地签装优先调度，优化多设备实机图显示，统一 MeoW 同版本补丁提醒。
