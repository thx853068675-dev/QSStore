# 轻启·安装器 0.4.38

## 修复

- 修复 `Cannot verify key and certificate: certificate is not P-256`（`SIGNING_MATERIAL`）：账号中遇到非 P-256 叶证书时，原生校验不再抛错并打断复用检查；P-384 私钥、证书、CSR 与 HAP 签名现在也受支持。仅密钥与叶证书公钥相同才会复用，其他证书继续检查。
- AGC 证书链中的 P-384 根证书是正常情况。校验使用依赖库验证并排序后的叶证书，不把根证书当作本机签名证书。本机已取得的一份 AGC 证书链是 P-384 根证书、P-256 叶证书；报错账号的原始证书链尚未取得。
- 保持“先复用、后申请”顺序；本次修复本身不申请、不删除 AGC 证书。

## 验证

- Rust 5 项单测通过，包括 P-384 根证书在前、P-256/P-384 叶证书的私钥匹配、P-384 CSR 公钥与签名核验；ArkTS/Node 106 项通过。
- 正式 HAP 已经官方 SDK `verify-app` 验签，并覆盖安装在 HarmonyOS 6.1 设备 `3BH0224320005595`。系统报告版本 `0.4.38` / `2026093002`，应用可启动。
- 尚未拿到报错账号的原始证书链，也未用另一个账号完整走 AGC 发证、签名和安装。因此本轮能证明错误路径已正确处理，不能宣称该账号的端到端流程已通过。
