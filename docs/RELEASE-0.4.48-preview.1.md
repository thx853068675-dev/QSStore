# 轻启·安装器 0.4.48-preview.1

48 预览版 1，同版本替换更新。安装器详情 → 版本记录 → 预览版，手动选择安装。

## 更新

- 本地支持 HAP、APP，以及包含 APP/HAP 的 ZIP；先预览名称、版本与包信息，再加入安装队列。
- APP 各 HAP 模块统一重签并提交安装；压缩包自动检查有效安装包，多个候选可选择。
- 上架支持多包同时选择，详情可切换安装包；服务端后台解析压缩包，保留旧客户端单包接口兼容。
- 后台安装申请官方长时任务；修复系统下载挂起、回前台时被误判超时的问题。
- 详情顶部固定与渐变模糊、进度圆角裁切、星数对齐与安装队列按钮样式调整。
