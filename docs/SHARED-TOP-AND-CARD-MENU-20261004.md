# 顶部渐变与卡片菜单验证

## 实现

- `StoreDesign.ets` 的 `StoreTopStyle` 集中管理顶部高度、滚动过渡范围和渐变参数。发现与管理保留官方 HDS 的 `IMMERSIVE_GRADIENT_BLUR`，共同调用 `navigationStyle()`；详情、本地签装、包编辑、应用信息复用 `StoreTopFade`。
- 公共渐变组件高度从 82vp 调整为 55vp；HDS 的延伸区域从 24vp 调整为 16vp。组件的透明度渐变在两端缓变，详情页滚动显示采用 smoothstep 过渡。
- 队列和已安装卡片共用主题化操作弹窗。背景、文字、普通操作和危险操作使用应用的深浅色配色；系统返回、点击遮罩和取消只关闭弹窗。选择后重新检查实时任务或安装记录，避免对已完成任务执行过时操作。
- 正常续签入口收入已安装卡片长按菜单，续签进行中仍在到期时间右侧显示“续签中”，点击重新打开现有进度弹窗。
- 开发者身份旁显示真实接口返回的实名认证布尔状态。旧缓存没有该字段时不误报“未实名”；没有读取或显示实名姓名，也没有额外账号请求。
