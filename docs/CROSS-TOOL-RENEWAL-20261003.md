## 实机发现并修复的本地导入问题

同一文件以前安装成功后，`pruneCompleted` 可能清理缓存并清空任务路径。`enqueueLocal` 重新导入该文件时复用完成记录，却没有绑定新导入的路径。任务恢复按在线下载规则生成 `0-<sha>.hap` 路径，实际文件为 `local-<sha>.hap`，误报「本地 HAP 完整性已改变」。实机复制源文件核对，SHA-256 正确；任务数据库确认路径错误。

修复完成记录复用分支：绑定新 cachePath / signedPath 和本次解析的身份信息，然后进入同版本重装流程。新增清空路径、旧路径两种回归场景。

## 源包与自动续签边界

- 续签需要可重签的完整应用包，不要求用户每次手动提供最初下载的文件。商店可以重新取同版本制品，本地应用可以保留一个可用源包。
- 这台 7.0 对 `/data/app/el1/bundle/public/com.rzdpaitt.musictt/musichomesample.hap` 的 shell 读取和 HDC file recv 都返回权限拒绝。没有证明安装器能自动取回任意已安装 HAP。
- 目前安装任务缓存会在超过 24 小时或总量超过 512 MB 后清理，不能当作长期续签源包库。若实施自动续签，需单独设计源包保留与用户清理策略；APP 多模块需要保留完整模块集。
- 同一仓库、同一开发者账号或同一包名本身不足以证明覆盖兼容。本样本的不同证书凭一致的非空 appIdentifier 被系统接受。其他来源需要逐个检查身份，不能自动卸载规避冲突。
- 自动调度还需处理 Profile 刷新、源包缺失、无线调试连接、后台执行及失败退避，目前不宣称这些已完成。
